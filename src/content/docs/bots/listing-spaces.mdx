## Introduction

To interact with Hymenia, the Hymenia API, hosted at `https://api-hymenia.dotun.cc` is used.
In this guide, we will run our first request to the API, viewing what spaces it is in.

## Method

For sending requests to the API, many languages can be used. If you would like
to use a more visual UI, [HTTPie](https://httpie.io/app) is a good tool. Otherwise,
we will use Python, Curl, and JavaScript. Of course, they're not the only things
you can use to develop a Hymenia bot, but they're the ones we'll provide for now.

To view what spaces we are in, the endpoint used is `/api/spaces`. We need to also authenticate
with our bot token. However, whereas many other APIs use the HTTP Header `Authorization: Bearer xyz`
for authentication, for apps, Hymenia uses `Authorization: App xyz`, where xyz is the bot token.

<Tabs>
  <TabItem label="curl">
  ```bash
  curl --request GET \
       --header 'Authorization: App hm.app.YOUR_TOKEN_HERE' \
       https://api-hymenia.dotun.cc/api/spaces
  ```
  </TabItem>
  <TabItem label="JS (fetch)">
  ```js
  const options = {
    method: 'GET',
    headers: {
      Authorization: 'App hm.app.YOUR_TOKEN_HERE'
    }
  };

  fetch('https://api-hymenia.dotun.cc/api/spaces', options)
    .then(response => response.json())
    .then(response => console.log(response))
  ```
  </TabItem>
  <TabItem label="Python (requests)">
  ```py
  import requests

  headers = {
      "Authorization": "App hm.app.YOUR_TOKEN_HERE",
  }

  response = requests.request("GET", "https://api-hymenia.dotun.cc/api/spaces", headers=headers)

  print(response.text)
  ```
  </TabItem>
</Tabs>

If you provided the correct bot token in the correct format, then you should get a
response following this format:

```json
[
  {
    "id": "b42c2041-f48c-48a2-af21-cf5abbbc4030",
    "name": "Hymenia Docs",
    "visibility": "private",
    "created_at": "2026-10-25T16:45:00.000Z",
    "role": "member"
  }
]
```

If so, you have successfully made your first request to the Hymenia API, and have
gotten the list of spaces that the bot is in. Next, we will get the list of channels
in a space.
