## Introduction

In this guide, we will list the chats in a space.

## Method

For sending requests relating to specific spaces, the `id` value of the space is
used in the request URL. You should have gotten this from the last guide by
requesting all spaces that the bot is in. For the Hymenia Docs space, that's
`b42c2041-f48c-48a2-af21-cf5abbbc4030`. To get the list of chats, we need to send
a request to the endpoint `/api/spaces/:spaceId/chats`, replacing `:spaceId` with
the ID of the space we'd like to get info on.

<Tabs>
  <TabItem label="curl">
  ```bash
  curl --request GET \
       --header 'Authorization: App hm.app.YOUR_TOKEN_HERE' \
       https://api.hymenia.com/api/spaces/SPACE_ID/chats
  ```
  </TabItem>
  <TabItem label="JS (fetch)">
  ```js
  const options = {
    method: 'GET',
    headers: {
      Authorization: 'App hm.app.YOUR_TOKEN_HERE'
    }
  };

  fetch('https://api.hymenia.com/api/spaces/SPACE_ID/chats', options)
    .then(response => response.json())
    .then(response => console.log(response))
  ```
  </TabItem>
  <TabItem label="Python (requests)">
  ```py
  import requests

  headers = {
      "Authorization": "App hm.app.YOUR_TOKEN_HERE",
  }

  response = requests.request("GET", "https://api.hymenia.com/api/spaces/SPACE_ID/chats", headers=headers)

  print(response.text)
  ```
  </TabItem>
</Tabs>

If you provided a valid bot token & space ID, you will get a response following
this format:

```json
[
  {
    "id": "9be5bb93-fa73-4151-bb81-ebd0b6142c40",
    "space_id": "b42c2041-f48c-48a2-af21-cf5abbbc4030",
    "name": "general",
    "type": "text",
    "created_at": "2026-10-25T16:45:00.000Z"
  }
]
```

We are now able to get the list of chats that a bot can access by chaining
together both listing spaces, and listing chats. Next, we will send a
message to a chat.
