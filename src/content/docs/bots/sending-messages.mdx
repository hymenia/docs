## Introduction

In this guide, we will send a message to a chat using the Hymenia HTTP API.
It should be noted there also exists a websocket API for Hymenia. This should
be preferred if you are doing any actual work - for just sending one off messages,
the HTTP endpoint is fine.

## Method

To send a message to a chat, we need the chat ID (as retrieved previously), and
an access token of a bot in the space where said chat is.

To send a message, we can send a POST request to the `/api/messages` endpoint with
a **JSON** payload, with the values `chat_id` and `content` filled out, as such:

<Tabs>
  <TabItem label="curl">
  ```bash
  curl --request POST \
       --header 'Authorization: App hm.app.YOUR_TOKEN_HERE' \
       --header 'Content-Type: application/json' \
       --data '{
        "chat_id":"YOUR_CHAT_ID_HERE",
        "content":"Hello, world!" 
       }' \
       https://api.hymenia.com/api/messages
  ```
  </TabItem>
  <TabItem label="JS (fetch)">
  ```js
  const options = {
    method: 'POST',
    headers: {
        Authorization: 'App hm.app.YOUR_TOKEN_HERE',
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        chat_id: 'YOUR_CHAT_ID_HERE',
        content: 'Hello, world!',
    }),
  };

  fetch('https://api.hymenia.com/api/messages', options)
    .then(response => response.json())
    .then(response => console.log(response))
  ```
  </TabItem>
  <TabItem label="Python (requests)">
  ```py
  import requests

  url = "https://api.hymenia.com/api/messages"

  headers = {
      "Authorization": "App hm.app.YOUR_TOKEN_HERE",
      "Content-Type": "application/json", 
  }

  data = {
      "chat_id": "YOUR_CHAT_ID_HERE",
      "content": "Hello, world!",
  }

  response = requests.post(url, headers=headers, json=data)

  print(response.text)
  ```
  </TabItem>
</Tabs>
